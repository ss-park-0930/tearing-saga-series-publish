# 조사·정규화 작업 공간

이 폴더는 공개 가이드에 바로 노출되는 원고가 아니라, 출처를 추적하고 사실을 대조하기 위한 작업 데이터입니다.

## 원칙

1. 국내 잡지 스캔의 검수된 표기를 한국어 명칭의 1차 기준으로 사용합니다.
2. OCR은 검색 보조 수단일 뿐이며 스캔 이미지를 직접 확인하기 전에는 정식 표기로 채택하지 않습니다.
3. 숫자, 발동 조건, 영입 조건은 일본어 데이터 사이트와 영문 자료를 교차 검증합니다.
4. 온라인 문장을 복사하거나 직역하지 않고 사실 단위로 추출한 뒤 한국어로 새로 서술합니다.
5. 의견성 캐릭터 평가는 작성자 관점과 플레이 조건을 명시하고, 수치 데이터와 구분합니다.
6. 로컬 잡지 스캔 이미지는 공개 사이트나 이 저장소에 복제하지 않습니다.

## 흐름

`sources.json` → `npm run research:crawl` → `crawl/catalog.json` → 사실 추출 및 대조 → `content/<game>/guides/**/*.md`

수집 스크립트는 색인 페이지에서 제목, 소제목, 내부 링크만 저장합니다. 본문 전체를 보관하지 않으며, 상세 공략은 검수자가 여러 출처를 읽고 요약해 작성합니다.
