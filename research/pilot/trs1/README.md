# 티어링 사가 1편 파일럿 수집

1~3장의 사실 데이터를 여러 출처에서 대조해 저장합니다. 현재 표시명은 일본어 원문을 사용합니다.

## 확인된 충돌

- 3장 출격 상한: RRPG는 8명, 게임 공략 천마기사단은 10명으로 기록합니다. 후자는 배치 설명까지 제공하지만 실제 게임 확인 전까지 `conflict`로 유지합니다.
- 2장 클리어 후 `☆まもりの杖` 조건: RRPG는 `リー`, `プラム`, `ランのてかがみ`을 조건으로 적고, 다른 출처는 `リー`와 `プラム`의 존재만 명시합니다.

## 다음 검수

- 실제 게임 또는 게임 데이터로 3장 출격 상한 확인
- `☆まもりの杖` 이벤트 플래그 확인
- 1~3장 승리·패배 조건의 게임 내 문구 확인
