# 공략 콘텐츠 구조

두 작품의 공략은 같은 분류 체계를 사용하되 작품별 경로에서 독립적으로 관리합니다.

- `trs1`: 《티어링 사가 - 유토나 영웅전기》
- `trs2`: 《베르위크 사가 - 라즈베리아 연대기 제174장》

## 분류

| ID | 화면 표시 | 내용 |
| --- | --- | --- |
| `getting-started` | 시작하기 | 기본 조작, 게임 흐름, 초보 팁 |
| `chapters` | 장별 공략 | 승리 조건, 증원, 영입, 대화, 보물, 턴별 전략 |
| `characters` | 캐릭터 | 영입, 성장률, 스킬, 클래스 체인지, 지원, 운용 평가 |
| `equipment` | 장비·아이템 | 무기, 마법, 지팡이, 도구, 상점, 입수처, 합성 |
| `skills` | 스킬 | 발동 조건, 효과, 습득자, 활용법 |
| `classes` | 클래스 | 기본 능력, 상한, 이동 비용, 클래스 체인지 |
| `secrets` | 비기·주의 요소 | 비기, 버그, 숨겨진 상점, 놓치기 쉬운 이벤트 |
| `data` | 데이터 | 계산식, 지형, 지원 효과, 투기장 등 수치 자료 |

## Markdown 작성 규칙

모든 공략 문서는 YAML front matter에 다음 필드를 가집니다.

```yaml
---
id: trs1-chapter-01
game: trs1
category: chapters
title: "1장 - 웰트 상륙"
status: outline
sources:
  - korean-magazine
---
```

`status`는 `outline`, `draft`, `reviewed`, `published` 순서로 올립니다. 수치나 이벤트 조건은 서로 독립적인 출처 두 곳 이상에서 대조하는 것을 원칙으로 하며, 전략 평가는 사실 데이터와 분리해 서술합니다.

온라인 공략 원문을 그대로 저장하거나 번역하지 않습니다. 사실을 추출해 재구성하고 문서 하단에 출처 URL과 확인일을 남깁니다.

패치가 완성되기 전까지 캐릭터·무기·아이템·클래스·스킬 이름은 일본어 원문을 표시명으로 사용합니다. 한국어 후보는 용어 사전에만 저장하고 공략 본문에 확정 표기처럼 사용하지 않습니다. 검수된 한국어 장 제목은 예외입니다.
